# Changelog

## 0.1.1 - 2026-10-25

- Cross-platform production build.
- Current Community installation documentation.


All notable changes to Archive Viewer are documented here.

## 0.1.0 - 2026-06-08

- Initial local release.
- Add read-only `.zip` archive metadata view.
- Add ZIP central-directory parser with no archive extraction or decompression path.
- Add contents tree, entry metadata table, summary pills, search/filter, refresh, and listing caps.
- Add warnings for path traversal, absolute paths, hidden/system-looking paths, encrypted entries, huge uncompressed sizes, many-file archives, and suspicious compression ratios.
- Add fixtures for simple archives, nested folders, path traversal, many files, large metadata, and malformed input.
